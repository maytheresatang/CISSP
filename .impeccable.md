# Design Context

Written by hand. The `/impeccable` command was not installed in the session, so this is not its output. Items marked (confirm) are guesses for May to check.

## Product
- Personal CISSP study notes site, CBK 2024, 8 domains plus a search bar.
- One user: May, studying for the CISSP exam in 2026.
- Static HTML. No build step. One `search.js` shared by all pages.

## Users and use
- Reader is May, on desktop and phone (confirm).
- Jobs: review a domain, scan weak areas, check quiz scores, find a term fast.

## Brand and tone
- Calm, serious, exam-focused (confirm).
- Plain, short sentences. Singapore Straits Times style.

## Current visual system (observed)
- Colours as CSS variables: navy `#0A1628`, teal `#0D9488`, amber `#B45309`, red `#B91C1C`, green `#15803D`, page `#F8FAFC`.
- Font: system sans stack. No web font.
- Light only. No dark mode.
- Cards with 12px radius, teal hover border, 960px content column.
- Status shown with coloured badges and callouts.

## Known weak spots to review
- Each page repeats its own `<style>` block. No shared stylesheet.
- Colour carries status. Check contrast and add text or icon cues.
- Text is 15px body, 11-13px for labels. Check readability on phone.
- Home page has no clear "start here" or "next to study" action.

## Principles for changes
- Keep it light and fast. No frameworks.
- Do not change note content. Change layout and style only.
- Move shared styles to one `styles.css` before restyling.
